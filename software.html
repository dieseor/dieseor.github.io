Software

Code accompanying my papers.

  • gofmetric Coming soon

    R package. Accompanies Goodness-of-fit for distributions on metric spaces (Serrano, García-Portugués and Van Keilegom, 2026).

    Kolmogorov–Smirnov and Cramér–von Mises goodness-of-fit tests built from distance profiles, on Euclidean, spherical, hyperbolic, compositional and product spaces. Simple and composite null hypotheses, calibrated by multiplier bootstrap. The repository will be made public soon.

    Paper Replication code
  • oob_balls

    Python. Accompanies Out-of-bag prediction balls for random forests in metric spaces (Serrano and García-Portugués, 2025).

    Out-of-bag prediction balls for random forests with responses in a metric space, built on pyfrechet, together with the code to reproduce every figure and table in the paper.
